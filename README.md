# LG GALAXY // webOS DATA PLANE — ACR · AD-TECH · BUYER PIPELINE

3D interactive map (planets = zones, satellites = services, streams =
links) of the LG smart-TV data ecosystem: what a webOS TV collects, the
LG cloud estates it reports into, the ACR/ad-tech partners in the chain,
the programmatic buyer pipe, and the last stop before the data is sold.

- Zones: 9 · Services: 33 · Links: 46
- Data: `data.json` (`{zones, services, ipPools, links}`) — every node
  carries the endpoints, DNS, ASN and disclosure text collected for it
- Render: open `index.html` in any browser (three.js + 3d-force-graph
  via CDN, no build)
- Live: https://saviorsec.github.io/lg-galaxy/

## The short answer

TV -> LG cloud (SDP + lgtvcommon.com data plane) -> ACR (Gracenote +
Alphonso Inc = LG Ad Solutions) -> audience segments -> programmatic
buy pipes (Amazon Publisher Services / Amazon DSP) and advertisers ->
the data-broker ecosystem. LG's own CCPA disclosure lists the categories
it sells or shares and the recipient classes; LG Ad Solutions markets
363M+ "addressable secondary devices" built from TV-side network
discovery of non-LG devices.
